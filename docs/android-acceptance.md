# 安卓安装与真机验收

本文是待执行清单，不代表已经在手机通过。版本0.1.0，包名 `cn.tiredwhite.zhixing`，AppID `__UNI__435D6C0`。

## 安装与首次连接

1. 机主已反馈在安卓手机安装交付的正式签名APK。首次启动、应用页面及后续功能结果仍待机主反馈；首次安装若手机询问是否允许当前文件来源安装，确认文件来自本项目后由机主操作；无需关闭系统安全防护。
2. 打开“知行”，进入“连接设置”。服务器填写 `https://tiredwhite.cn`。
3. 在电脑打开忽略目录 `.local/secrets/知行连接信息.txt`，把其中的应用连接令牌填入手机并保存。它不是DeepSeek模型密钥。不要把服务端模型密钥填写到手机。
4. 粘贴自行编写的测试通知，例如“请于2026年10月23日18:00前到教学楼A201提交项目书PDF”，选择AI解析；确认来源显示真实AI、日期及原文依据正确，再保存。

手机中的 `127.0.0.1` 指向手机自己，不能用于连接电脑或云服务器。卸载应用会删除应用本地数据，卸载前先导出备份。

## 测量与证据

记录手机型号、Android版本、网络类型、APK SHA256、测试日期、每项是否通过和异常截图。正式性能指标应在手机测量；Windows到公网API的耗时只能作为另一种环境的参考。采集10次非缓存实时请求的成功/失败数及耗时，P95采用nearest-rank，即升序排列第 `ceil(0.95 × n)` 个成功请求。

## 版本更新

更新包须保持包名与签名证书不变，并递增versionCode。私有签名证书及密码在部署者电脑 `.local/secrets`，须单独备份；项目源码和公开交付包不包含这些凭据。安装覆盖更新后仍需验证已有任务保留。
